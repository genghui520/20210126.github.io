## 常用 Git 命令

- `git add -A`：添加所有修改和新建的文件到暂存区。
- `git commit -m "your message"`：使用说明性的提交信息创建一次提交。
- `git push origin master`：第一次提交推送到远程 `master` 分支。
- `git push`：后续提交直接推送当前分支。
- `git pull`：抓取远程仓库最新内容并合并。
